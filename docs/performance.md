## 0.5.8 位置与尺寸使用相同缩放比例

以可用区域中心为基点，将源窗口中心的偏移乘以窗口缩放比例，再进行位置求解和候选评分。窗口缩到 50% 时，原来相距 2000 像素的两个中心，其目标距离改为 1000 像素。实际位置仍受边界、标题间距和动画路径约束，不能由这个目标距离推断所有场景的最终覆盖率。

已显示的预览位置用于约束连续操作的运动路径，直接使用当前坐标，不重复缩放。

## 0.5.7 局部重排

最小化和关闭窗口后，先保留已经验证能放下的旧比例，再搜索更大的可行布局。局部移动的距离不设硬性上限；小场景降低旧位置的权重，并细化缩放比例。已有预览继续保留分离运动路径，底部区域高度变化时也不再丢弃这些关系。动画中再次操作时，以当前采样位置判断路径。

用修改前生成的同一组 596 个最小化场景检查新旧算法，其中 498 个场景的旧布局仍放得下：不必要的缩小从 87 次降为 0，新的布局全部满足边界、间距及分离路径检查。普通窗口内容占上方区域的平均比例从 40.31% 增至 41.34%。这不是逐场景都变大或全局最优的保证；底部区域变高、或需要避免运动交叉时，比例仍可能受限。

240 组连续最小化的中途打断检查通过；32/64 位构建各通过 39 项布局、76 项原生预览和 4 项中途重新展开检查。原生画面恢复时主体像素最大通道差为 0，清理后 DComp/D3D 设备引用为 0/0。上述结果来自固定几何场景与隔离虚构窗口，不代表屏幕帧率或所有第三方应用组合。

## 0.5.6 再次打开

每次重新打开都重新计算布局，包括收回动画尚未结束时再次展开；局部调整产生的坐标只用于连续操作。60 组先局部删窗、再重新打开的检查中，新结果均与直接求解一致。中途反向时也重新求目标位置，并在计算完成后采样当前动画位置，避免倒退。

双屏、12 个隐藏虚构窗口的隔离测试中，触发闲置清理后再次准备场景，7 次测量的中位数如下：

| 阶段 | 0.5.5 | 0.5.6 |
| --- | ---: | ---: |
| 壁纸准备 | 184.88 ms | 0.29 ms |
| 场景准备至合成提交完成 | 301.94 ms | 69.27 ms |

这里直接调用闲置清理流程，比较其对下次准备的影响，不含热键接收、真实窗口枚举与屏幕首帧。不是完整操作延迟或 FPS 测量。自动、常驻模式在闲置后保留最多 64 MiB 壁纸像素缓存；这是像素容量上限，不是进程或驱动总内存上限。

## 0.5.5 大量窗口与后台开销

- 大量窗口的候选布局复用真实方位权重，用评分上界提前排除不可能胜出的候选；删除已经被更长路径蕴含的冗余间距约束。保留自由坐标、窗口面积权重、统一缩放与运动分离规则，小场景的独立参考坐标保持一致。
- 文字、宽度、DPI 与连接圆角未变时复用标题表面和图层；同 DPI 的字体格式复用。500 条连续位置通知按最终真实尺寸合并处理，不增加轮询或延迟定时器。
- 每个显示器复用壁纸表面；缓存命中时仅检查文件时间戳，不重复枚举系统壁纸。显示器、设置与主题通知使缓存失效。窗口层次使用索引更新，顺序未变时不重建图层树。
- 未选中的窗口不创建选框和按钮相关的五个合成对象，也不提交它们的动画。动画中首次悬停时，装饰加入原来的绝对时间轴。相同动画的查询改为索引，避免大场景逐条扫描。
- 后台采用事件等待，动画一次性提交给 DWM。关闭总览会解除窗口事件钩子；60 秒后关闭任务栏读取线程，保留排序快照供下次直接使用，再异步刷新。0.5.5 同时清空壁纸缓存，0.5.6 改为上述有容量上限的缓存。自动模式保留设备以便快速展开，省内存模式释放设备并回收工作集。

在同一台 Windows 11 机器上交替运行三次，纯几何基准的中位数如下。多屏场景是确定性几何模型，窗口总数平均分配到各屏；这些时间不含原生窗口枚举、DWM 画面绑定和首次显示，也不代表屏幕帧率。

| 总窗口数 / 显示器数 | 0.5.4 首次布局 | 优化后首次布局 | 0.5.4 新增窗口 | 优化后新增窗口 |
| --- | ---: | ---: | ---: | ---: |
| 128 / 1 | 44.94 ms | 19.27 ms | 30.67 ms | 21.10 ms |
| 256 / 1 | 277.85 ms | 55.86 ms | 241.72 ms | 72.64 ms |
| 512 / 1 | 1425.74 ms | 220.93 ms | 1242.22 ms | 171.51 ms |
| 512 / 2 | 577.28 ms | 109.81 ms | 1648.95 ms | 160.08 ms |
| 512 / 4 | 212.45 ms | 55.79 ms | 384.85 ms | 87.45 ms |

128 个隐藏虚构源窗口的资源基准中，重复标题准备约从 20–30 ms 降至 0.05 ms，双屏壁纸缓存查询约从 8–10 ms 降至 0.1 ms。原生画面绑定仍是首次准备的重要开销。实际 240 Hz AMD 内屏与 160 Hz NVIDIA 外屏已做 128 个虚构窗口的合成检查，但抓屏采样会引入额外跨显卡复制，目前不据此声称 FPS 提升。

自动模式经过 60 秒缓存回收，再采样 20 秒，进程 CPU 时间增量为 0 ms、I/O 为 0、没有待触发的定时器；这表示测量区间内近零后台活动，不表示进程或保留设备不占内存。省内存模式已验证释放图形设备。布局回归新增 64–512 个窗口、等价评分与约束蕴含检查，原生回归检查标签复用、首次悬停和通知合并。

## 回归范围

0.5.5 的 32/64 位构建各通过 39 项布局检查、76 项原生预览检查，最终 DComp/D3D 设备引用为 0/0。任务栏排序、手势交互、原生圆角像素检查和独立版自检通过。本机已验证独立版连接 Explorer 及两种位数的 Windhawk 模组实际加载。

这些结果来自开发机器与隔离测试窗口，不代表全部 Windows 版本、驱动或第三方应用组合。
