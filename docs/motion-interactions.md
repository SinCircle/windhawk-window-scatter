# 任务栏折叠与最小化窗口飞出

窗口继续使用原有的单段平稳过渡，无弹性回弹、悬停收缩、方向牵引或整屏渐变。外部选中框及关闭、最小化按钮保留。全部窗口在一屏内自动排布，不提供横向滚动。

进入总览时，最小化窗口从对应任务栏按钮的实际位置、宽度和高度开始，分别过渡到预览宽高，允许长宽比在过程中变化。优先匹配准确的窗口按钮，其次应用分组；无可靠按钮信息时回退到该屏任务栏区域。

任务栏使用独立的原生共享画面，位于预览上方。窗口先从按钮下方出现，任务栏在同一合成时间线上稍后沿所在屏幕边缘折叠；退出时恢复。已有自动隐藏状态不变。

退出的最后 35% 时段渐入窗口的真实 DWM 外侧阴影，再直接交接到原生窗口。阴影只采样可见边框外沿，不重复叠加窗口内容；退回任务栏的最小化预览不显示窗口阴影。中途重新打开时从当前阴影透明度渐出。总览停留时不显示阴影，也不加入整屏渐变。

任务栏区域不绘制过渡阴影，包括任务栏的半透明部分。每个显示器使用一个共用裁剪边界，跟随该屏任务栏折叠、恢复和反向运动；只裁剪阴影，保留窗口内容原有的运动。顶部、底部、左侧和右侧任务栏均按各自边缘处理，不增加逐帧 CPU 更新。

三指选窗按滑动方向选取邻近窗口，支持斜向；每次切换使用归一化位移 0.085，并保留 90 毫秒防止连续误切的间隔。屏幕上不绘制虚拟光标。短上滑释放保留总览；进入选窗后至少操作 220 毫秒，释放才进入选中窗口。不使用窗口大小自动减速。

验证区分自动化布局和原生合成检查，以及真实触控板体验。不会因模拟消息通过而声称真实手感已经验证。

中键点击预览或其标题关闭该窗口；Shift＋中键按窗口 AppUserModelID、进程 AppUserModelID 或可执行文件路径分组，向同应用分组的所有任务栏窗口发送正常关闭请求，覆盖其他显示器、虚拟桌面和最小化窗口。隐藏辅助窗口和工具窗口不在此范围内，应用可以提示保存或取消关闭。按下后拖到其他预览、背景或失去鼠标捕获都会取消该次操作。

同批关闭通知在重排前合并，其他显示器的布局目标不重算。阴影采样优先复用当前几何对应的已验证源矩形，尺寸变化时重新校验；同一提交中相同的延迟动画复用合成对象。这些优化不改变退出阴影的原生像素、时序和中途反向行为。

同批新增窗口先统一接入画面，再计算一次布局和标题。重复状态通知合并处理；任务栏快照只在最小化栏排序改变时触发重排，按钮位置变化只更新返回位置。窗口位置、圆角、标题透明度、阴影与任务栏在中断时取同一时刻的状态，命中测试也对整组窗口共用一次时间采样。

窗口重排保留正在进行的手势选中项；选中窗口被关闭时自动转到剩余候选。左键点击需在同一目标上按下、松开，失去捕获、拖到其他预览或释放到总览之外会取消操作。应用标题改变时只更新对应标题和必要的选框，继续使用原有动画的绝对起始时刻。

准备布局、标题或原生阴影期间，旧动画仍由 DWM 播放。中断时保留原时间轴，在准备结束后按合成器预计交接帧重新采样全部通道；新曲线的起点与绝对开始时间对齐。首次静止展开则在动画对象建立完成后选择起始帧，保留开头的播放时间。原有单段曲线和设置时长不变。

阴影四个边缘互不重叠，可分别乘以透明度，避免先合成整窗大小的透明中间层。重新展开完成后将不可见阴影从活动视觉树摘下，缓存保留以供下一次退出。短暂的系统合成时钟请求只覆盖动画播放期间，完成或取消时释放；是否升频由当前显示设备和系统决定。

每个总览窗口在第一次显示之前设置 Windows 文档规定的 `NonRudeHWND` 属性，使覆盖屏幕的系统辅助界面不参与自动全屏判定。这样不会因进入总览而自动打开勿扰，也不会把短暂出现的勿扰铃铛带入任务栏退出动画。此属性只属于总览窗口，不修改系统通知或勿扰规则。接口依据见 [Microsoft 的全屏窗口说明](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-itaskbarlist2-markfullscreenwindow)。

## 任务栏折叠设置（1.0.5）

`foldTaskbar` 默认开启，独立版存储为 `FoldTaskbar`，缺失值按开启处理。关闭时任务栏共享画面的展开和收起位置相同，原有连续动画与阴影裁剪沿用这组固定端点；各屏幕使用同一选项。设置更新经过现有结束总览、重新加载配置的路径，下一次进入使用新值。原生任务栏的自动隐藏状态不做修改。
