# 预览素材

[返回项目首页](../../README.md)

首页素材录制于 Windows 11，使用 0.5.5 对应的 `window-scatter.wh.cpp` 原生渲染代码。六个独立 Win32 窗口由文档录制程序创建，设计稿、代码、笔记、文件列表、音乐和日历均为虚构内容。背景同样专为录制绘制；没有使用真实应用数据或用户壁纸。

| 文件 | 展示内容 | 来源 |
| --- | --- | --- |
| `overview.gif` | 原位置展开、悬停选中、切换并回到目标窗口 | 7.5 秒原生合成录制 |
| `minimize.gif` | 总览内最小化、移入底部、选择并恢复 | 8 秒原生合成录制 |
| `overview.png` | 总览完整静态画面 | 展开录制的第 3 秒 |
| `detail.png` | 选中框、附着标题和操作按钮 | 同一原始帧的裁剪，未重新绘制界面 |
| `icon.png` | 项目标识 | 独立版构建生成的应用图标 |

窗口预览来自 DWM 共享画面，布局和动画由生产实现执行。文档程序只注入虚构窗口、示例背景和预定操作序列，不调用生产 `Begin()` 枚举真实应用，也不安装全局热键或系统入口连接。录制因此展示真实的布局与原生合成效果，但不用于证明热键、触摸板或系统入口链路；这些行为另有专项检查。

原始素材在 150% 显示缩放下，以 1440×900、目标 30 fps 捕获；GIF 缩小到 1080×675、25 fps，并进行调色板压缩。录制与编码会增加负载，GIF 帧率不等于产品帧率，也不用于性能比较。帧间没有补间生成，预览没有经过 AI 重绘。

## 复现

需要 Windows 11、LLVM-MinGW、FFmpeg，以及主显示器至少 1440×900 的可用工作区。在仓库根目录运行：

```powershell
.\tools\record-preview.ps1 -Compiler 'C:\path\to\llvm-mingw\bin\clang++.exe'
```

脚本短暂显示虚构窗口，录制两段场景，然后将 GIF 与静态图写入本目录。原始无损录像保留在被 Git 忽略的 `build/readme/`。按 Esc 可中止；若其他进程的窗口遮住捕获区域，程序会停止写入画面并返回错误。运行完成后关闭录制窗口，恢复此前的前台窗口。

发布前检查全部帧，确认没有其他应用内容、遮挡、交接重影或意外黑帧。不同 DPI 下布局会变化，细节图的裁剪区域需要按实际结果调整。不要将失败或中止的录制替换到首页。文档录制工具不会修改已安装的模组或用户设置。
